How do I add a custom token to MetaMask on the right network?

How to add a custom token to MetaMask: choose its network, paste the official contract address, confirm the token details, and import it to see your balance.

By Blockchain Today EditorialNov 28, 2026 · 04:42 UTC4 min read

A custom token import can make a token you hold appear in MetaMask’s Tokens list with its balance. MetaMask shows many popular tokens automatically, but a token it hasn’t picked up may need to be added by contract address. This process is for the browser extension and mobile app on EVM networks.

You’ll need MetaMask open, the token’s contract address from an official source, and its network added to your wallet. A USDC bridge moves USDC from one blockchain to another; that network-to-network transfer makes it a useful example of why the destination network matters. A token on Base must be imported while MetaMask is set to Base.

Import the token on the network where it lives

MetaMask’s import flow adds a token by its contract address, while the network selector determines which chain’s token balance you’re viewing. Follow these steps in order:

  1. Switch MetaMask to the token’s network. Use the network selector at the top of the wallet and select the chain where the token contract exists. If that network is not available, add it to MetaMask before continuing.
  2. Open the Tokens tab and choose Import tokens. In the browser extension, the import option may appear under the token list or its management controls. In the mobile app, expand the token list and tap the plus button to start importing.
  3. Choose Custom token and paste the token’s contract address. Copy it from the issuer’s official site or the relevant chain explorer, such as Etherscan for an Ethereum token or Basescan for a token on Base. Don’t use an address sent in a chat or shown in an ad.
  4. Confirm the symbol and decimals MetaMask fills in. These values come from the token contract. Make sure the address is the one you intended to import; a token name or symbol by itself does not identify a contract.
  5. Tap Next, then Import. MetaMask adds the token to the wallet’s list for the selected network. Importing makes the token visible in MetaMask; it does not move tokens between networks.
  6. Look in the Tokens list and compare the displayed balance with the token balance on that same network. The import worked when the token appears with the expected balance.

Check the contract details when a familiar symbol looks wrong

A token’s symbol is only a label; different contracts can use the same one. Searching by name can surface lookalike tokens, so use the contract address published by the issuer or shown on the correct chain’s explorer. An explorer can help confirm that an address belongs to a token contract on that network.

Decimals are a useful check because they control how the contract’s token units are displayed as a balance. USDC uses six decimals on EVM chains. If an address labelled “USDC” fills in 18 decimals, it is not Circle’s USDC. A copied symbol can look right even when the contract is different; the decimals come from the contract, not the symbol.

Say you transfer USDC to Base and then open MetaMask on Ethereum. The expected Base balance won’t appear there because the wallet is showing a different network. Switch to Base, then import Base’s USDC contract address if the token is not already listed. The balance appears under the network where those tokens were received.

MetaMask’s token display rules explain why importing can be necessary: the wallet may show popular tokens by default, while an unlisted token can be added manually by address. The trade-off is that manual import gives you control over what appears, but it also means you must verify the address yourself. Look at the network, contract address, symbol, and decimals together before importing.

How do I hide a token in MetaMask?

Open the token’s menu and choose Hide or use the token management controls to turn its display off. On mobile, MetaMask’s help instructions say to long-press the token to show the hide option. Hiding a token removes it from the visible list; it does not change the token balance on its network.

Why does my imported token show a zero balance?

A zero balance can mean the wallet is set to the wrong network, the address belongs to a different token contract, or the token is not held by the selected account. Confirm the network and account first, then compare the imported contract address with the one shown by the issuer or chain explorer. For a transfer, check that the receiving transaction completed on that network.

Once the balance matches, keep the network and contract address handy for the next time you need to verify the asset. That check helps distinguish a missing display from a balance held on another chain or under a different contract.

How do you buy a token on Arbitrum One from an exchange?

Buy ETH on your exchange, withdraw it to a wallet on Arbitrum One, then use Matcha swap to trade for the token and confirm its balance in the wallet.

By Blockchain Today EditorialNov 25, 2026 · 17:08 UTC6 min read

To buy a token on Arbitrum with money from a centralized exchange, buy ETH there, withdraw it to your own wallet on Arbitrum One, then swap it for the token. This route puts the token in a self-custody wallet, with ETH available to pay Arbitrum One gas.

Have a self-custody wallet, an exchange that supports Arbitrum One withdrawals, and the target token’s official contract address ready. Add Arbitrum One to the wallet before withdrawing. Arbitrum One uses chain ID 42161; Arbiscan is its blockchain explorer. Arbitrum Nova uses the same address format, but it is a different network.

How do you get from exchange funds to a token in your wallet?

Follow these steps in order. Each stage gives you a way to check that the funds are where you expect before moving on.

  1. Add Arbitrum One to your wallet. In MetaMask, select Arbitrum One or add it using the wallet’s network settings. Confirm the selected network is Arbitrum One, chain ID 42161. Result: your wallet is ready to display and receive funds on that network.
  2. Buy ETH on the exchange. Choose an amount that leaves some ETH available after the swap. Arbitrum One gas is paid in ETH, even if you later choose to swap USDC. How much you need depends on the transactions and current network conditions, so leave a practical reserve rather than planning to spend the full balance. Result: ETH appears in your exchange balance.
  3. Withdraw ETH to your wallet address on Arbitrum One. Copy the address from your wallet and select Arbitrum One as the withdrawal network on the exchange. Check the address and network carefully before confirming; the exchange’s supported withdrawal networks determine which route is available. Result: the exchange reports the withdrawal as processing or complete, with a transaction hash once available.
  4. Confirm the transfer on Arbiscan. Paste the transaction hash into Arbiscan and inspect its status and destination address. A completed withdrawal at the exchange does not by itself tell you which network your wallet is displaying. Result: you can see whether the transfer reached the address on-chain.
  5. Switch the wallet to the network that received the funds. Arbitrum One and Arbitrum Nova share the same address format. If you withdraw to Nova, those funds can arrive at your address while MetaMask is set to Arbitrum One, making the wallet look empty on that network. Match the network shown for the transaction on Arbiscan to the network selected in the wallet. Result: the wallet displays the funds on the network where they arrived. If the transaction is on Arbitrum One but the balance still looks wrong, verify the address and asset shown in the wallet.
  6. Connect your wallet to Matcha swap on Arbitrum and select the token. Choose ETH as the input and paste the target token’s contract address as the output. A name or ticker alone can point to a different token; compare the contract address with the project’s official source. Check that the selected network is Arbitrum One. Result: the swap interface identifies the intended output token and shows a quote. At this point, matcha mobile is another way to access Matcha swap while you’re arranging the exchange.
  7. Review the quote and confirm the swap. Check the output token, estimated amount, and transaction details before approving. Keep enough ETH for gas; the wallet may need ETH for the swap transaction even when the input is another asset. Confirm in the wallet and wait for the transaction to complete. Result: the target token balance appears in your wallet on Arbitrum One. The task is complete when the wallet is on Arbitrum One and shows the token you intended to buy.

Take a simple case: you buy ETH on an exchange, withdraw it to your MetaMask address using Arbitrum One, and see the completed transaction on Arbiscan. You connect to Matcha swap, paste the token contract, review the quote, and confirm. The ETH balance falls by the swap amount and gas; the target token then appears in the wallet. Save the transaction hash and contract address so you can check the exact transfer and asset later.

Once the token appears, compare its contract address and network with your records. That gives you a clear reference if the balance later seems missing or you need to check the token before transferring it.

Related questions

What if my exchange doesn’t support Arbitrum withdrawals?

You need a withdrawal route the exchange supports. Check its available networks for ETH and whether Arbitrum One is listed. If it isn’t, don’t select a different network on the assumption that it will arrive on Arbitrum One; funds sent on another network arrive there instead. Use a supported route only if you understand how you’ll get the funds onto Arbitrum One afterward.

Is USDC.e the same as USDC on Arbitrum?

No. Native USDC and bridged USDC.e are different tokens on Arbitrum. Check the contract address and token shown in your wallet or swap quote before choosing either one. If you plan to swap USDC, confirm that Matcha swap is using the variant you hold and that you still have ETH for gas.

How much ETH should I keep on Arbitrum for gas?

Keep enough ETH to cover the transactions you plan to make, including the swap. The amount needed varies with network conditions and the transaction, so check the wallet’s estimate when you submit. If you spend all your ETH on the token, you may need another ETH transfer before you can make a further transaction on Arbitrum One.

What should you do next?

How do I send tokens from Arbitrum back to an exchange?

Check that the exchange accepts deposits of that specific token on Arbitrum One. Copy its deposit address and select Arbitrum One as the network in your wallet when sending. Confirm the token, network, and address before you submit, then check the transaction on Arbiscan. A deposit sent on a network the exchange doesn’t support may not credit as expected.

How do I find a token’s official contract address?

Use the token project’s official website or another official project channel, then compare the address with the token details shown on Arbiscan or in your wallet. Search results and token names can include look-alikes. Match the full contract address and the Arbitrum network before swapping or adding the token to your wallet.

Can I set a limit order for a token on Arbitrum?

Order types depend on the trading interface and the token pair available there. Check the current options in the interface before planning a limit order; a swap quote is not a limit order. Make sure you understand the order conditions and keep ETH available for network transactions.

What do I do if I withdrew on the wrong network?

Find the transaction hash in the exchange’s withdrawal history and inspect it on the explorer for the network used. Since Arbitrum One and Nova share an address format, first switch your wallet to the network where the transfer arrived and check the balance there. If the destination was an exchange address or a network the exchange doesn’t support, contact the exchange with the transaction hash and ask about recovery options.

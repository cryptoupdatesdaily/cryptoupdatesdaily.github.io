Network directory websites: Can they access wallet funds?

Can a network directory website access my wallet funds? No: connecting shares your public address, and adding a network saves settings; signing is what can authorize fund movement.

By Blockchain Today EditorialNov 18, 2026 · 17:13 UTC4 min read

A network directory helps your wallet connect to an EVM network by supplying its Chain ID and RPC endpoint. No: connecting to a directory shares your public address, and adding a network saves settings; neither step gives the site control of your funds. Your private key stays in your wallet. A fund-moving transaction or token approval requires a signature from you.

Can a network directory website access my wallet funds?

A directory cannot move funds just because you connect or add a network. The two prompts have different jobs: the connection prompt lets a site see an account address, while the add-network prompt asks your wallet to save network settings. Neither prompt is a transaction or token approval.

Say you open Chainlist to add a network to MetaMask. First, the wallet asks whether to connect the selected account. If you accept, the site can see that account’s public address. It does not receive your seed phrase or private key. You can decline the connection, or disconnect later, without changing the wallet’s stored funds.

Next, when you choose a network and click add, the site sends a wallet_addEthereumChain request. EIP-3085 defines this request for suggesting a chain to a wallet. It carries network details, such as the Chain ID, RPC URL, native currency and, where supplied, block explorer. The wallet displays a separate prompt so you can review and accept or reject those settings. The [EIP-3085 specification](https://eips.ethereum.org/EIPS/eip-3085) describes adding a chain as a request to update the wallet’s list of chains.

Accepting saves network settings in the wallet; it costs no gas because it does not submit an on-chain transaction. It also does not send your tokens anywhere. The network may not become active automatically: that depends on the wallet. You can then use it to view balances or interact with apps on that network.

For this situation, chainlist.org lets you choose network details for your wallet to save. Chainlist’s role in that step is to send the add-network request; the wallet still shows the prompt and keeps control of signing.

  • Connect: The site receives the selected public account address after you approve the connection.
  • Add network: The wallet saves a Chain ID, RPC endpoint and related network settings after you approve the prompt.
  • Sign or approve: Your wallet authorizes a message, transaction or token permission that may enable an action involving funds.

The practical dividing line is the signing prompt. A real add-network flow never needs a signature, transaction or token approval. If a page claims it is only adding a network but asks for one of those, stop and treat the page as a clone. Read what the wallet says you are signing: a token approval can give a contract permission to spend tokens later, while a transfer can send them immediately. Losses can follow from signing those requests on lookalike sites, even though connecting and saving a network did not move the funds.

MetaMask’s [instructions for adding a network](https://support.metamask.io/hc/en-us/articles/360043227612) describe reviewing and confirming the network in the wallet. A prompt asking for a transaction or token approval is a different action. Close it if it does not match what you intended to do.

Can a malicious RPC endpoint steal crypto?

A malicious RPC endpoint cannot sign for you, but choosing one has privacy and reliability trade-offs. Your wallet uses the endpoint to read network data and send requests. The endpoint can see your IP address and the activity and transactions you send through it. It may also return misleading network information, so review the Chain ID and endpoint before accepting a network.

Adding a network is therefore a settings decision, not a transfer of custody. For a first-time user, the useful checks are whether the prompt is only asking to add a network, whether its Chain ID matches the network you intended to use, and whether the RPC endpoint is one you trust. Keep the wallet closed if the request turns into a signature, approval or transaction you did not expect.

Is it safe to connect my wallet to Chainlist?

Connecting shares your selected public address with the site. Review the domain and approve the connection only when you want that site to see the address; connecting alone does not authorize a transfer.

Can a malicious RPC endpoint steal crypto?

An RPC endpoint can observe requests and may provide unreliable information, but it cannot use your wallet’s private key to sign. Check the endpoint and network details, and review every wallet signing prompt before approving it.

When adding a network, approve only the wallet prompt that saves the settings; reject any unexpected request to sign, approve tokens or send a transaction.

BEP-20 is BNB Smart Chain’s token standard

What is the BEP-20 token standard? It is BNB Smart Chain’s token format, built around familiar ERC-20 functions and used with 0x addresses on chain ID 56.

By Blockchain Today EditorialNov 26, 2026 · 06:41 UTC4 min read

BEP-20 is the token standard used on BNB Smart Chain, and it gives tokens a familiar set of functions for sending and tracking balances. Its tokens use 0x addresses on the network’s mainnet, which has chain ID 56. The name matters when you choose a network in MetaMask or send a token: the token and the wallet must be on the same network.

BNB Smart Chain is EVM-compatible, so it reused Ethereum’s ERC-20 token interface. That makes BEP-20 familiar to people who have used Ethereum tokens, while the network remains BNB Smart Chain. Chainlist adds network details such as chain IDs and RPC endpoints, which help connect a wallet or Web3 tool to the right network.

What BEP-20 means

BEP-20 is a shared specification for tokens on BNB Smart Chain. A token contract follows the standard functions so wallets and other tools can interact with it in a predictable way. ERC-20 is the closest comparison: BEP-20 mirrors its core interface because both networks use the Ethereum Virtual Machine.

The listed functions include transfer, approve and balanceOf. A token contract uses transfer to move tokens, balanceOf to report a wallet’s token balance, and approve to let another address spend an allowed amount. BEP-20 also includes getOwner. These shared functions explain what the standard is for; they do not make every token the same asset or give tokens the same value.

Take USDT on BNB Smart Chain. It is a BEP-20 token contract. To see it in MetaMask, select BNB Smart Chain and import the token using its contract address. The address identifies that token contract on that network. The ticker “USDT” alone is not enough to identify which contract or network you mean.

How BEP-20 appears in a wallet

A BEP-20 token uses a normal 0x address on BNB Smart Chain. The network’s mainnet Chain ID is 56. When you add or select that network in MetaMask, the Chain ID identifies which network the wallet is connected to; the token contract address identifies the token on it.

That distinction is useful when receiving or sending tokens. A 0x address can look familiar from Ethereum, but the network still matters. Select BNB Smart Chain for a BEP-20 transfer, and check that the receiving wallet or service supports the same network. Chainlist can supply the network connection details, while the token’s contract address points to the specific token.

In practice, think of the network and token contract as two separate choices. First, connect to BNB Smart Chain, identified by chain ID 56. Then use the contract address for the BEP-20 token you want to view or send. A correct-looking 0x address does not by itself tell you that the wallet is on the intended network.

BEP-20 and BEP-2 are different

BEP-20 is not BEP-2. BEP-2 was the token standard on the retired BNB Beacon Chain, and BEP-2 addresses used the bnb1 format. BEP-20 belongs to BNB Smart Chain and uses 0x addresses. The different address formats reflect different networks and standards.

This is the key practical difference for a MetaMask user: a BEP-20 token can be used with a 0x wallet address on BNB Smart Chain, while the older BEP-2 format used bnb1 addresses. Do not treat the standards as interchangeable just because both names begin with “BEP.” When a token or service names one of them, match that standard to its network before sending.

The change to an EVM-compatible network and familiar ERC-20 functions makes BEP-20 easier to recognize for someone who already knows Ethereum tokens. The trade-off is that familiar address formatting can obscure the network choice: 0x indicates the address style, not whether a wallet is connected to Ethereum or BNB Smart Chain. Keep the token standard, network and contract address in view together.

What to check before a transfer

Before sending, check that the token is BEP-20, the wallet is on BNB Smart Chain with chain ID 56, and the contract address is the one for the token you intend to use. For USDT, importing its contract address on chain 56 makes the BNB Smart Chain token appear in MetaMask. For an older BEP-2 reference, the bnb1 address format signals that it is associated with the retired BNB Beacon Chain.

BEP-20 means a token follows BNB Smart Chain’s ERC-20-style interface; chain ID 56 and a 0x address identify the network context to check when handling it.

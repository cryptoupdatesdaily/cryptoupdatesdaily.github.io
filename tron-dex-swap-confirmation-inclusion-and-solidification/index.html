TRON DEX swap confirmation: inclusion and solidification

How long does a TRON DEX swap take to confirm? Usually seconds for block inclusion and about a minute for the transaction to become irreversible.

By Blockchain Today EditorialNov 17, 2026 · 00:20 UTC4 min read

A TRON DEX swap is usually included in a block within seconds and becomes irreversible in about a minute. Wallet signing, broadcast delays and network conditions can extend the wait, so a submitted swap and a settled swap are different stages.

On SunSwap, a swap exchanges TRC-20 tokens through liquidity pools, making it a useful case for following what happens between wallet approval and finality. Its shared pools also make what SunSwap carries between trades a concrete example of how one trade can leave state that matters to later trades.

A TRON swap moves through signing, inclusion and solidification

A TRON DEX swap passes through three stages: wallet signing, block inclusion and solidification. The distinction explains why a wallet can show that a transaction is pending even though the swap has not yet completed.

  1. Signing: TronLink asks you to review and sign the swap. Until you approve it, the transaction has not been sent to the network. A delay at this point is in the wallet step, not block production.
  2. Broadcast and inclusion: After signing, the wallet broadcasts the transaction. TRON produces blocks at roughly three-second intervals, so a broadcast swap may appear in a block after a few intervals. The wallet or node response and current network conditions can affect how quickly it reaches one.
  3. Solidification: Inclusion is not the final confirmation stage. A block is considered solidified after 19 of the 27 active Super Representatives have built on it or on a later block. That typically takes about a minute.

Say you approve a SunSwap token swap in TronLink. The signing step may be quick, and the transaction may then show a block after a few roughly three-second intervals. You still need to allow time for that block to become solidified; seeing it included is progress, while solidification is the stronger sign that it is irreversible.

This is the key comparison: “in a block” answers whether the network included the transaction; “solidified” answers whether it has reached the finality threshold. A swap can therefore appear to have gone through before the full confirmation wait is over.

What should you check if the wait grows?

Use the transaction ID in TRONSCAN to locate the transaction and follow its block and confirmation status. Then inspect the execution result to see whether the swap succeeded; a transaction being visible is not, by itself, proof that the swap completed successfully.

If TronLink is still waiting for your signature, finish or reject that prompt first. If you signed but cannot find the transaction in a block, the delay is earlier in the process: it may relate to broadcast, a node response or changing network conditions. Once a block is shown, follow confirmation status as solidification continues.

Suppose the same SunSwap swap takes longer to appear in a block because broadcast or network conditions have slowed. That changes the wait before inclusion, so the overall time grows. The part that still holds is the distinction between stages: block inclusion and solidification remain separate, and the transaction’s status and execution result in TRONSCAN tell you where it stands.

Use the observed status to decide what to do next rather than treating every wait as the same problem. A missing block points to a delay before inclusion; a block that is not yet solidified points to the later confirmation stage. If the execution result shows the swap failed, it did not succeed even if the transaction was included.

Related

How many confirmations does a TRON transaction need?

A TRON transaction is considered solidified after 19 of the 27 active Super Representatives have built on its block or a later one. Since blocks arrive roughly every three seconds, this threshold typically takes about a minute; block inclusion alone is an earlier stage.

Why is my TRON swap still pending?

A TRON swap may still be pending because it has not been signed, broadcast or included in a block yet, or because it is still progressing toward solidification. Use TronLink to complete the signing step and TRONSCAN to check the transaction ID, block status and execution result.

For a typical swap, expect block inclusion within seconds and about a minute for solidification. The deciding reason is that inclusion and irreversibility are separate stages, so the status and execution result show whether you are still waiting or the swap is complete.

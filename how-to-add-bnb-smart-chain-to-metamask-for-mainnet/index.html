How to Add BNB Smart Chain to MetaMask for Mainnet

To add BNB Smart Chain to MetaMask, connect through Chainlist, approve the Mainnet details, and select the network before using apps or receiving assets.

By Blockchain Today EditorialNov 26, 2026 · 14:46 UTC4 min read

To add BNB Smart Chain to MetaMask, connect the wallet to Chainlist, choose BNB Smart Chain Mainnet, review and approve its network details, then select the network in MetaMask. MetaMask needs the network’s RPC endpoint and Chain ID to communicate with it.

Chainlist is a directory of EVM networks and their connection details; MetaMask is the wallet that stores the network settings you approve. That network context also helps explain what BEP-20 means on BNB Smart Chain, since BEP-20 is a token standard associated with the network.

Choose BNB Smart Chain Mainnet and review its details

BNB Smart Chain Mainnet is the choice for connecting MetaMask to the network used with real assets. Its Chain ID is 56, also written as 0x38, and its native currency is BNB. MetaMask presents the network details for review before it adds the network, so check that the request identifies Mainnet and shows the expected Chain ID.

Start with MetaMask installed and unlocked. Open Chainlist, search for BNB Smart Chain Mainnet, connect MetaMask, and choose the matching network entry. In MetaMask’s prompt, review the network name, Chain ID, RPC endpoint, and currency details. Approve the request if they match the Mainnet entry, then select BNB Smart Chain from MetaMask’s network menu.

The RPC endpoint is the connection MetaMask uses to communicate with the network. The Chain ID identifies which network the request is for. These details are why adding a network is an approval step: MetaMask asks you to review what it will use before saving the settings.

Mainnet and testnet are separate networks. Choose Mainnet when your task involves real assets. A testnet selection connects MetaMask to a different network, so it is not interchangeable with Mainnet for that purpose. The network name and Chain ID in the approval prompt help you confirm which one you are adding.

Selecting BNB Smart Chain changes the network MetaMask uses

Selecting BNB Smart Chain tells MetaMask to use that network’s settings for compatible apps and wallet activity. It does not move assets from another network or change which network a sender uses. The wallet holds network settings; choosing one changes the active connection.

Say you have just approved BNB Smart Chain Mainnet and want to receive an asset. Select BNB Smart Chain in MetaMask first, then make sure the sender also chooses BNB Smart Chain for the transfer. If the sender uses another network, adding BNB Smart Chain to your wallet does not redirect the transfer onto it. The sender and recipient need to use the same network for the asset to arrive on BNB Smart Chain.

That distinction matters because a wallet can show network settings without moving funds between networks. Adding BNB Smart Chain gives MetaMask the connection details; selecting it makes it the active network. For an incoming transfer, check the network with the sender before they send. For an app, select BNB Smart Chain before using it.

Keep BNB available on BNB Smart Chain for transaction fees. BNB is the network’s native gas currency, so having assets in a wallet is separate from having the currency needed to pay fees for activity on that network. Before a transfer or other transaction, confirm both the selected network and that BNB is available for gas.

Related questions

Does MetaMask support BNB Smart Chain?

Yes. Add BNB Smart Chain to MetaMask by approving its network details, then select it from MetaMask’s network menu.

What do I need to pay gas on BNB Smart Chain?

BNB on BNB Smart Chain pays transaction fees. Keep some BNB available on that network when you plan to make transactions.
